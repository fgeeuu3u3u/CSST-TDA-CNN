# SLS_1D_SPEC

#### 介绍
一维无缝光谱仿真，包含望远镜的特性
1-d csst slitless spectroscopic simulation, include the charactor of optical system, grating, ccd and so on.

1. sh install.sh
2. cd example, and  "python sim_demo1.py"
